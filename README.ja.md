# ideathon-20210424

このリポジトリには、2021年4月24日に開催された「5G x デジタルツインアイデアソン」イベントの資料が含まれています。

## 内容

本リポジトリには、イベントのプレゼンテーション資料が以下の形式で含まれています。

*   `20210424-5Gxデジタルツインアイデアソン.pptx` (Microsoft PowerPoint)
*   `20210424-5Gxデジタルツインアイデアソン.key` (Apple Keynote)

これらのファイルを閲覧するには、Microsoft PowerPointやApple Keynoteなどの対応ソフトウェアが必要です。
